# GLÖGGT – leiðbeiningar

Þessi mappa er lifandi notendahandbók GLÖGGT.

Markmiðið er að skrá raunverulegt vinnulag jafnóðum og það er staðfest í kerfinu. Leiðbeiningar eiga því að þróast samhliða kóðanum, ekki vera skrifaðar löngu eftir á.

## Reglur

- Skrifa fyrst það sem notandi þarf að gera: **svona gerir þú**.
- Nota sömu orð og hnappa og sjást í GLÖGGT.
- Aðgreina staðfesta virkni frá hugmyndum eða framtíðaráætlunum.
- Uppfæra leiðbeiningu þegar vinnuferli breytist.
- Vinnudagbók og Git geyma þróunarsöguna; þessi mappa lýsir núverandi vinnulagi.
